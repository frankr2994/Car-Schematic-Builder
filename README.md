# Wiring Schematic Designer

A vertical slice of a React-based schematic designer.

## Features
- Schema-validated save files
- ELK.js orthogonal auto-layout
- Interactive component dragging (persists locally)
- Decoupled model (connections separated from display ports)
- Print-ready viewport styling

## Scripts
- `npm run dev` - Start development server
- `npm run build` - Build production bundle
- `npm test` - Run test suite
- `npm run lint` - Run ESLint
- `npm run typecheck` - Run TypeScript compiler checks
